## CoreStack

CoRE Stack (Aaditeshwar Seth's project) is the main platform underlying FPL's climate/ESG work. Code lives across two orgs: `core-stack-org` (upstream) and `fplaunchpad` (FPL's contributions).

#### Repo

1. [core-stack-org/core-stack-backend](https://github.com/core-stack-org/core-stack-backend) (core-stack-org, Aaditeshwar Seth's team, IIT Delhi): Django app that computes layers (LULC, drought, hydrology, etc.), serves the API, and orchestrates GEE/GeoServer.
2. [core-stack-org/landscape-explorer](https://github.com/core-stack-org/landscape-explorer) (core-stack-org): React + OpenLayers frontend for viewing layers.
3. [core-stack-org/Commons-Connect](https://github.com/core-stack-org/Commons-Connect) (core-stack-org): Vite/React app for watershed planning, run inside a Flutter WebView.
